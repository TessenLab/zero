# Project Zero assets

Public visual assets for the Project Zero repository live here.

## Hero banner

Canonical repository path:

```text
assets/project-zero-banner.png
```

The approved banner direction is the monochrome Project Zero particle-network artwork with:

- black background;
- white / gray node field;
- PROJECT ZERO;
- MORE DEVELOPERS · MORE NODES · MORE INTELLIGENCE;
- no fabricated network statistics.

The README is intentionally text-first until the approved binary asset is committed at the canonical path.

## Asset rules

- Do not publish internal screenshots containing credentials, private endpoints or private telemetry.
- Do not add invented developer counts, Node counts, capacity or uptime to artwork.
- Keep launch-state copy accurate: `COMING` before certification, `OPEN` only after the public Zero path is certified.
- Prefer repository-owned assets rather than temporary external image hosts.
