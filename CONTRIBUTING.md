# Contributing to Project Zero

Thanks for your interest in Project Zero.

This repository is currently the **public documentation and launch home** for Project Zero. Tessen's private platform source code is not contained here.

## Before the Zero Pool opens

Useful contributions include:

- documentation corrections;
- questions that expose unclear onboarding;
- reproducible problems in public launch material;
- accessibility or compatibility issues in public Project Zero surfaces once available.

Please do not submit speculative implementation code for private Tessen services.

## Security

Do not file security vulnerabilities as public issues. Follow [SECURITY.md](./SECURITY.md).

## Accuracy

Project Zero intentionally distinguishes:

- shipped vs planned;
- available vs coming;
- measured vs targeted.

Contributions must preserve that distinction. Do not add fabricated metrics, unsupported performance claims or unverified installation instructions.

## Code contributions

If Tessen opens code components for contribution, their scope, license and development workflow will be documented explicitly. A public documentation repository should not be interpreted as an open-source license for private Tessen code.
