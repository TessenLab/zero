# Project Zero Roadmap

This is a public launch roadmap, not a promise of dates.

## Now — Coming

- Public Project Zero GitHub home
- Platform and Console launch readiness
- Project Zero end-to-end certification
- OpenCode integration certification
- Tessen CLI public-release certification
- Tessen Node public-release certification
- independent Tessen Status
- developer identity and auth closure
- usage, cost, reliability and abuse telemetry

## Opening gate

The Zero Pool opens when a clean developer can:

1. discover Project Zero;
2. authenticate through a supported public method;
3. enter the developer Console;
4. follow real setup instructions;
5. make a successful Project Zero coding request;
6. return later successfully;
7. see honest service status and documentation.

## After opening

Priorities become evidence-driven:

- activation;
- Day-1 / Day-7 / Day-30 retention;
- request success and latency;
- developer feedback;
- Node adoption and reliability;
- sustainable capacity and cost;
- developer-tool integrations.

## Later

Additional editor, desktop, mobile and developer integrations can follow after the core Zero loop is reliable.

No roadmap item in this document should be interpreted as a guaranteed ship date.
