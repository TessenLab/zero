# Project Zero FAQ

## What is Project Zero?

Project Zero is Tessen's free developer intelligence preview focused first on real coding workflows.

## Is it live?

Not publicly yet. **The Zero Pool is coming.** The public path is being certified before install and credential instructions are published.

## What will it cost?

The developer preview is planned at **$0**. Usage is still metered and program limits can apply.

## Is it unlimited?

No. Tessen can apply allocations, rate/concurrency controls, eligible routing and abuse protections.

## What model do developer tools use?

```text
tessen/project-zero
```

## Where will I use it?

The first public paths are being prepared around Tessen Platform, Tessen Console, OpenCode and Tessen CLI.

## What is Tessen Node?

Tessen Node is the desktop participation layer for Tessen's distributed compute direction. It is intended to let supported machines contribute available compute under explicit controls.

## Is there already a huge Node Pool?

We are building the pool. We will publish Node and capacity statistics only when production telemetry supports them.

## Is the 100,000 developer number current traction?

No. **100,000 activated developers is a target.** It is not a claim about current usage.

## Can I join now?

Watch or star this repository. Public onboarding will be added here when the Zero Pool opens.

## Will Project Zero always be free?

This repository describes the Project Zero preview. Future commercial Tessen Code offerings can be separate from the preview.

## Is Tessen open source?

This public repository documents Project Zero. It does not imply that Tessen's private platform, Gateway, infrastructure or other products are open source.

## Can I contribute?

Before launch, the most useful contribution is feedback on the public concept and documentation. Code contribution boundaries will be documented separately if/when components are opened.
