# Project Zero in OpenCode

OpenCode is planned as one of the first coding environments where developers can experience Project Zero.

## Model reference

```text
tessen/project-zero
```

The developer-facing identity stays stable while Tessen can evolve eligible routing behind the Gateway.

## Intended launch flow

1. Install a certified supported OpenCode build.
2. Sign in to Tessen through the supported developer flow.
3. Obtain Project Zero access.
4. Select `tessen/project-zero`.
5. Work in a real repository.

## Why OpenCode

Project Zero should meet developers where coding work already happens. OpenCode provides an agentic developer workflow without requiring Tessen to invent a separate editor just to make Zero useful.
