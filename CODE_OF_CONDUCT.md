# Project Zero Community Conduct

Project Zero is intended to be a useful, technical and welcoming developer community.

## Expected

- Be respectful and direct.
- Critique ideas and implementations, not people.
- Share reproducible technical information when reporting problems.
- Respect privacy, credentials and unpublished security information.
- Make clear when a claim is measured, inferred, planned or experimental.
- Help keep discussion useful to developers.

## Not acceptable

- Harassment, threats or discriminatory abuse.
- Publishing private information or credentials.
- Deliberately misleading performance, usage or network claims.
- Spam, scams or impersonation.
- Public disclosure of an unpatched security vulnerability before Tessen has had a reasonable opportunity to investigate it.

## Security reports

Security vulnerabilities should be reported privately according to [SECURITY.md](./SECURITY.md), not discussed in a public issue.

## Moderation

Tessen may remove content or restrict participation when necessary to protect the community, the project or its users.

Questions about this policy can be sent to **hello@tessen.ai**.
